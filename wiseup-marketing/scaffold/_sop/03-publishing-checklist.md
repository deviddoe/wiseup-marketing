# SOP 03 - Publishing checklist (for the owner)

Before publishing anything at `approved`:

- [ ] the status really is `approved`
- [ ] the link carries its UTM and actually opens
- [ ] text on the visual renders correctly, including on a phone
- [ ] price and terms match `_context/product-offering.md`
- [ ] for an ad: budget, audience and dates match the campaign file
- [ ] for an ad: analytics and the conversion pixel are confirmed working (check once, before the first launch)

After publishing, tell Claude: **"published <file>, url: <url>"**. The CMO sets `published` and records the link so the analyst can measure the result.
